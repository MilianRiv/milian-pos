# Milian POS · Demo en vivo / Live demo

**ES** · Demostración web de *Milian POS*, un punto de venta multipropósito (tienda, restaurante y farmacia) hecho con Flutter.
Pruébalo en **https://milianriv.github.io/milian-pos/** · usuario de demostración: botón «Entrar con el usuario de demostración».

- Los datos son **ficticios** y se guardan solo en tu navegador (SQLite en WebAssembly); no se envía nada a ningún servidor.
- Este repositorio contiene únicamente el **build compilado** de la demo. El código fuente del producto es privado.
- La demo no incluye licencias ni impresión térmica (funciones de la versión de escritorio).

**EN** · Web demo of *Milian POS*, a multi-purpose point of sale (retail, restaurant and pharmacy) built with Flutter.
Try it at **https://milianriv.github.io/milian-pos/** · use the «Entrar con el usuario de demostración» (demo user) button.

- All data is **fictional** and stored only in your browser (SQLite on WebAssembly); nothing is sent to any server.
- This repository only holds the **compiled build**. The product's source code is private.
- The demo omits licensing and thermal printing (desktop-version features).
